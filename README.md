# B.R.T.P.S - Better RTP for Server

## How to get JAR online (no install)

1. Create GitHub repo at github.com/new
2. Upload ALL files from this zip (including .github folder)
3. Go to Actions tab > Click "Build B.R.T.P.S Jar" > Run workflow
4. Wait 1 minute > Download artifact "BRTPS-jar"
5. Inside it is BRTPS-1.0.0.jar - rename to BRTPS.jar
6. Put in plugins/ folder and upload to Modrinth

Or locally: mvn package
